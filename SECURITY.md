# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/backlundpf/speel/security/advisories/new)
rather than opening a public issue. Include the affected package(s) and version, and steps to
reproduce if you have them. You should get an acknowledgement within a few days.

## Supported versions

speel is in beta. Fixes land on the latest `0.x` prerelease; older prereleases are not patched.
